# Сессионный проект по безопасности GNU/Linux

**Курс:** «Безопасность GNU/Linux»  
**Тема:** Настройка базовых средств защиты ОС GNU/Linux  
**Операционная система:** РЕД ОС 8 (виртуальная машина VirtualBox)  
**Номер зачётной книжки:** М265824  
**Порядковый номер в группе:** 31

## Выполненные работы

В рамках сессионного проекта выполнены следующие действия:

1. Установлена и настроена РЕД ОС 8, проверена сетевая доступность.
2. Выполнено обновление системы, установлены необходимые пакеты, включая nginx и tcpdump.
3. Создан раздел на дополнительном виртуальном диске, настроено постоянное монтирование файловой системы ext4 в `/mephi-web` по метке `MEPHI_WEB`.
4. Настроен веб-сервер nginx для обслуживания страницы из `/mephi-web`.
5. Созданы пользователи и группы `developers` и `curators`; настроены права доступа, ACL, capabilities для tcpdump и контекст SELinux для веб-каталога.
6. Настроены параметры парольной политики и правила ограничения локального входа кураторов через PAM.
7. Проверена выдача веб-страницы с номером зачётной книжки.

## Примечание по безопасности

Файл `shadow` опубликован **в обезличенном виде**: значения поля с хешами паролей заменены на `[REDACTED]`. Оригинальный `/etc/shadow` не размещается в публичном репозитории по соображениям безопасности. Опубликованные материалы предназначены для подтверждения выполнения учебного задания.
